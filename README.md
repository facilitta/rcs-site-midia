# Mídia do site da Rio Christian School

Arquivos da pasta do Drive do site, organizados nas mesmas pastas das páginas (`academico/anexo/` corresponde a `/academico/anexo/` no site).

- Fotos: iguais ao original, só com o nome trocado para não ter espaço nem acento.
- Vídeos: imagem copiada sem recompressão, com faststart; o áudio LPCM virou AAC. Cada vídeo tem uma capa `.poster.jpg` ao lado.
- Acima de 100 MiB: não cabem no git e ficam nas [Releases](https://github.com/facilitta/rcs-site-midia/releases), uma por página (`proposito/chapel` vira a Release `proposito-chapel`).
- Educação inclusiva, Feiras e projetos e Prédio: as pastas estão vazias no Drive.

Link direto de um arquivo: `https://raw.githubusercontent.com/facilitta/rcs-site-midia/main/<pasta>/<arquivo>`.
